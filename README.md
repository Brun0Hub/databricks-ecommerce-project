# Databricks E-commerce Analytics Project

This project demonstrates an end-to-end analytics solution built on Databricks following the Medallion Architecture.

## Technologies

- Databricks
- Unity Catalog
- PySpark
- Delta Lake
- SQL
- Power BI

## Architecture

- Bronze Layer
- Silver Layer
- Gold Layer
